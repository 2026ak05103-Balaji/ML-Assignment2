# Wisconsin Breast Cancer Model Comparison

## a. Problem statement

This project compares five supervised classification models for predicting
whether a breast mass is malignant or benign from its digitized image-derived
measurements. It is an educational classification demonstration, not a medical
diagnostic tool.

## b. Dataset description

The Wisconsin Diagnostic Breast Cancer dataset has **569 instances**, **30
numeric features**, and a binary target. The features describe properties of
cell nuclei computed from digitized fine needle aspirate images. Target values
are `0` for malignant and `1` for benign. The dataset is distributed with
scikit-learn and originates from the
[UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).

`train_models.py` uses a stratified 80/20 split with a fixed random seed. The
test partition is saved as `test_data.csv`; it contains all required features
and the target column.

## d. Models used

All five classifiers are trained on the same training partition. Standard scaling is included in the Logistic Regression, K-Nearest Neighbors, and SVM pipelines; the saved pipeline applies the same preprocessing during evaluation. The app loads these saved pipelines and never retrains on uploaded test data.

## Run locally

1. Install the dependencies with `pip install -r requirements.txt`.
2. Train and save the five models and the sample held-out CSV with
   `python train_models.py`.
3. Start the interface with `streamlit run app.py`.
4. Upload `test_data.csv` or another labeled test CSV containing all 30
   feature columns and `target` (`0` = malignant, `1` = benign).

The app displays Accuracy, AUC, weighted Precision, weighted Recall, weighted
F1, and MCC for every saved model, along with a confusion matrix for the
selected model. If the uploaded target contains only one class, AUC is
undefined and is shown as unavailable.

## Files

- `app.py` — Streamlit evaluation interface.
- `train_models.py` — reproducible training, evaluation, and artifact creation.
- `models/` — serialized fitted scikit-learn pipelines.
- `test_data.csv` — stratified held-out test data for the app.
- `metrics.json` — measured metrics generated by the training script.
